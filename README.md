# Project Overview

This project is a multi-page website for the fictional company Fox Valley Art Installations (FVAI). The site introduces the organization, describes its services, provides information about the team, includes a contact page, and allows visitors to suggest an art project.

## Planning and Project Organization

The project was planned entirely on paper and through group discussions during class time. Tasks were divided among the team members based on their strengths and interests:

- Ray handled the overall styling and created the services page.
- Min created the home and about pages.
- Micah created the contact page and all JavaScript functionality.
- Ray and Micah worked collaboratively on the contact page.

## Form Submission

The current HTML forms are front-end demonstrations and are not connected to a back-end server. To submit form data to a back-end server, the form buttons would need to use `type="submit"` instead of `type="button"` so that the browser could submit the form data to the server to be stored and manipulated.

If the forms were connected to a back-end server, JavaScript functionality would likely be little to none. Server-side code would handle receiving, processing, validating, and storing the submitted information.

## AI Assistance

AI was used minimally for debugging and for other small, tedious tasks. It was not used to write the actual code.
